# Проверка клиента в Codespaces

Codespaces предназначен для разработки и тестирования проекта. Постоянный хостинг бот-процесса не входит в этот режим использования. Низкий RSS не гарантирует отсутствие ограничений аккаунта. Codespace также останавливается по idle timeout, исчерпанию квоты или максимальному сроку сессии; остановка завершает процессы. Здесь нет обхода этих ограничений.

Условия: https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#codespaces

## Ограниченный интеграционный тест

```sh
npm ci --ignore-scripts
npm test
node tools/test-session.js start --initial 10 --max 500 --grow-seconds 1 --grow-by 2 --minutes 60 --name 'nbtest' --regions CN,RU,KZ,UA,BY,PL,GB,US
node tools/test-session.js status
node tools/candidates.js status
node tools/proxy-watch.js status
node tools/test-session.js stop
```

Менеджер запускает два рабочих процесса и следит за общей памятью вместе со своей: предел 320 МиБ RSS. Worker ботов: heap 128 МиБ, RSS 160 МиБ; worker прокси: heap 64 МиБ. При приближении к пределу RSS приостанавливается создание новых ботов; при превышении жёсткого бюджета все процессы теста завершаются. Heap и RSS — разные величины. Статусы записываются каждые 1–2 секунды, дампы пакетов выключены, лог клиента подавлен.

В начале подключаются 10 аккаунтов, затем добавляется два в секунду, максимум 500. Восемь одновременно выполняемых подключений и ответы сервера могут замедлять фактическую регистрацию. Регистрация подтверждается после LoginOk и Home с заданным именем. Серверный отказ в регистрации останавливает увеличение числа ботов. Сетевая ошибка одного аккаунта не останавливает остальные. Все аккаунты сохраняются в `.runtime/candidates/accounts/`; повторный запуск использует их. Параметр `--manifest .runtime/manifest.json` принимает массив путей к уже сохранённым аккаунтам. `--prefix nbtest` задаёт имя с индексом.

«Кандидаты дня» — слот 12. Текущий ID извлекается из Home ограниченным экспериментальным сканированием; будущие и просроченные записи исключены, неоднозначность прерывает действие. Выбор дополнительно подтверждается TeamData от сервера.

Новый подбор разрешён только после непустого BattleEndMessage (23456) той же сессии, ранее получившей загрузку (24112/20559). Повторный цикл уже подтверждён живыми BattleEndMessage и повторными загрузками в Codespace. Затем клиент переподключается, получает свежий Home и выбирает текущий ID события. Разрыв соединения и таймер не подтверждают конец боя: фаза `result-unknown` требует проверки; `result-unconfirmed` означает 10 минут без результата.

С `--battle-transport udp` доступны кадры боя и нейтральные пакеты через UDP; подробности и ограничения в [BATTLE_UDP.md](BATTLE_UDP.md). Управление бойцом и автоматическое прохождение матча пока не реализованы. Подтверждение загрузки не означает завершение матча.

По умолчанию одновременно в подготовке/подборе находится один бот (`--max-queued 1`). Следующий начинает после серверного назначения матча или подтверждённой отмены. Это отдельно от скорости создания аккаунтов. Статус показывает прогресс `x/y` для каждого подбора; y берётся из ответа сервера. Условия разделения ботов и поведение при неизвестном исходе: [MATCHMAKING.md](MATCHMAKING.md).

## Прокси

8 источников: Proxifly (SOCKS5/HTTP), Monosans (SOCKS5/HTTP), TheSpeedX (SOCKS5/HTTP), Hookzof, Jetkai. URL находятся в `lib/ProxySources.js`. Списки читаются последовательно, максимум 256 КиБ с каждого; проверяется до 240 адресов за цикл, 12 одновременно, каждые 2 минуты. Источники чередуются, начальный индекс меняется, проверенные адреса также повторно проверяются.

Рабочим считается туннель, получивший корректный ServerHello именно от сервера игры. Результат сохраняется в `working-proxies.json` и `.txt`. Ошибка отдельного источника не отменяет остальные. Приватные IP и адреса с авторизацией из публичных списков исключены. Системный прокси/VPN не меняется. При сетевом разрыве Client переподключается с задержкой 1–32 секунды и заново читает пул; здоровые соединения не переключаются. Отказ сервера в авторизации не обходится сменой IP.

Оба процесса запускаются одновременно. Если пул пока пуст, процесс ботов остаётся запущенным и повторяет попытки соединения; проверка публикует первые рабочие прокси сразу, до завершения всего цикла. Тест также останавливается через указанные 1–60 минут. Для запуска клиента на собственном Linux-сервере доступен `tools/candidates.js` с отдельной настройкой периода работы; ограничения Codespaces нельзя превратить в гарантию постоянной доступности.

Файлы аккаунтов, токены, статусы и проверенные прокси не добавляются в Git и не входят в архив релиза. Перед переносом аккаунтов остановите старый процесс, чтобы избежать одновременного входа с двух устройств.

При пустом пуле, сетевых ошибках прокси и изменении списка отправляется внеплановая проверка, с защитой от частых повторов (не чаще 30 секунд). Внутренние записи проверки не запускают бесконечную повторную проверку.

`--regions CN,RU,KZ,UA,BY,PL,GB,US` выбирает каждому аккаунту случайную страну. Выбор сохраняется в аккаунте; подтверждённый ответ 24178 с кодом 0 и нужным регионом обязателен. Статус содержит `region` и `regionConfirmed`. Регион профиля не является подтверждением выбора физического игрового сервера.

`--name 'nbtest'` задаёт точный ник при создании каждого нового аккаунта, без суффикса номера. Если токен уже получен, но имя ещё не подтверждено, регистрация продолжает установку этого ника. Клиент сначала проверяет имя запросом 14600; ответ 20300 должен содержать код 0 и точное имя. Установка подтверждается серверной командой 201, затем повторным входом и Home. Отказ сервера отображается как `blocked` и приостанавливает создание новых аккаунтов. Существующие аккаунты с подтверждёнными именами сохраняют их. Чтобы заменить активную группу, сначала остановите сессию и переместите каталог `.runtime/candidates/accounts` в резервную папку, затем запускайте новую сессию. Не удаляйте токены ранее созданных аккаунтов.

Для остановки в заданный момент замените `--minutes 60` на `--until` с будущей датой ISO 8601. До указанного момента должно оставаться от 1 до 60 минут.
