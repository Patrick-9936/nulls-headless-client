# Источники

Основной источник форматов: ARM64 libg.so предоставленного Nulls v69.252, статически разобранная Capstone; выдержки находятся в docs/native, адреса и версии сообщений — docs/protocol-evidence.json. ELF-библиотека в выпуск не включена. Каталоги карт, бойцов и тексты ошибок получены из CSV установленного APK. Контроль: расшифрованные ответы сервера и бинарные фикстуры tests/fixtures.

Исторические публичные реализации использованы для поиска имён сообщений, а не как доказательство совместимости текущего формата:

- https://github.com/LekmaDev/BSV28/blob/main/PacketsHelper.py
- https://github.com/CrazorTheCat/BSDS-V41
- https://github.com/weeco/supercell-packet-listener

Файлы docs/native являются читаемыми дизассемблированными выдержками, не восстановленным исходным кодом сервера. Серверный генератор ID, база аккаунтов и исходники серверной части не извлечены.
