# nulls 0.2.6: tui и один файл
запуск: node Nulls.js
управление: стрелки вверх/вниз, enter; esc или q — назад; ctrl+c — закрыть tui и его соединения.
в форме /cancel возвращает назад. пути, ники, теги и сообщения вводятся текстом; команды вводить не нужно.
сначала «аккаунт и соединение» → загрузить сохранённый аккаунт или создать один новый.
для старого json выберите «указать другой путь» и абсолютный путь. файл аккаунта сохраняет тот же токен.
можно открыть несколько сохранённых сессий и переключаться между ними. действие выполняется только выбранной сессией.
закрытие tui отключает его сессии; чужой fleet не останавливается.
udp включён по умолчанию. для прокси выберите файл пула в настройках новых подключений.
в tui доступны все действия клиента; выбор бойца заблокирован как и в cli, экспериментальные функции отмечены.
список рекомендованных клубов, друзей и длинные ответы выводятся страницами.
графики боя нет: brawl tv использует существующий протокол и сохраняет его ограничения.
инструкции по игровым функциям, native evidence, данные, зависимости и тесты вложены.
аккаунты, токены и приватные рабочие дампы в сборку не включены.

один переносимый js содержит сжатый клиент и все его зависимости. нужен Node.js 20+, npm install не требуется.
первый запуск распаковывает клиент рядом с js в .nulls-single-0.2.6; там хранятся конфиг и новые аккаунты.
существующая исходная папка не изменяется. изменённый config.json в рабочей папке сохраняется при повторном запуске.
после распаковки можно отдельно запустить node .nulls-single-0.2.6/TUI.js.
node Nulls.js help — команды cli.
node Nulls.js info — версия и сервер.
node Nulls.js club-recommendations --account /полный/путь/account.json --once — прежние команды.
node Nulls.js --tool fleet status — вложенная утилита; остальные js-утилиты аналогично.
node Nulls.js --state-dir /полный/путь/папка tui — другая рабочая папка.
node Nulls.js --extract /полный/путь/пустая-папка — извлечь исходники, зависимости и инструкцию.
node Nulls.js --self-test — проверить целостность и синтаксис вложенных js без распаковки.
node Nulls.js --test — выполнить все встроенные тесты без игровых подключений.
не удаляйте рабочую папку, если в ней остались нужные аккаунты.
